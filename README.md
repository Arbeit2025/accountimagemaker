# accountimagemaker（アカウント画像ランダム生成）

アカウント用のアイコン画像をランダムに生成できる、単一ファイル Flask の Web ツールです。スタイルとサイズを選ぶと候補が6件表示され、気に入ったものを PNG でダウンロードできます。各候補には seed（乱数の種）が付いていて、同じ seed・スタイル・サイズではいつでも同じ画像が再現されます。

生成は Flask と Pillow のみで行い、データベースは使いません。画像はサーバーに保存されず、メモリ上だけで処理します。

## 使い方

1. トップページでスタイル（3種）とサイズ（256 / 512 / 1024）を選ぶ
2. 「候補を生成」を押すと、候補画像が6件表示される
3. 各候補の下の「ダウンロード」から PNG を保存する
4. 同じ画像をもう一度出したいときは、候補に表示された seed を控えておき、`/img?seed=<seed>&style=<スタイル>&size=<サイズ>` の形で直接開く

## スタイル（3種）

- **identicon** … 5×5 の左右対称ブロック模様（GitHub のデフォルトアイコン風）。背景と前景のコントラストが取れる配色で生成します
- **geometric** … グラデーション背景に、ランダムな円・三角形・線を重ねた幾何学模様
- **pixel** … 16×16 ドット絵の簡易フェイス。目の位置・高さ、口の形（笑顔／直線／開いた口／小さい口）、耳やアンテナなどのパーツがランダムに変わります

色パレットは seed から決定的に生成され、背景が明るいときは前景を濃く、背景が暗いときは前景を明るくして、コントラストが確保されるようにしています。

## ローカル起動

```bash
pip install -r requirements.txt
python app.py
# http://127.0.0.1:5000 を開く
```

## テスト

```bash
python -m unittest discover -s tests
```

テストは Flask のテストクライアント経由で、ネットワークへの実アクセスは行いません（トップページと /healthz の応答、PNG 生成、seed の再現性、サイズ指定の反映、不正パラメータ時の挙動を確認します）。

## 構成

- `app.py` … 本体（単一ファイル）
- `tests/test_app.py` … unittest
- `requirements.txt` … Flask / gunicorn / Pillow
- `render.yaml` … Render（Free）用デプロイ設定。起動コマンドは `gunicorn app:app`、ヘルスチェックは `/healthz`

## 由来

accountnamemaker（アカウント名候補メーカー）の姉妹作として、名前と画像をそろえて作れるようにする発想で作りました。名前の候補を決めたら、このツールでアイコン画像も用意できます。
